# Privacy Policy — PDF Tools - Merge, Split & Scan

Last updated: November 3, 2026

## Overview

PDF Tools - Merge, Split & Scan processes PDF and image files **locally on your device**. We do not operate a backend server for core PDF features in this version of the app.

## Data we process

Android cloud backup is disabled for app-private files and settings.

- **Files you select or create** (PDFs, images, scanned pages) are read and written on your device only.
- **Recent files metadata** (file name, path, size, feature used) is stored locally in an on-device database.
- **Reading position** is stored locally under the file path or a hash of the Android document URI.
- If you choose to save a reusable signature, its image is stored in PDF Tools' app-private storage on this device. You can delete it from the signing screen. Signatures not saved for reuse are kept only for the current signing session and output copy.

The signing feature adds a visual appearance to a PDF. It does not verify identity or create a certificate-based cryptographic signature. Recent-file records do not contain signature image bytes or annotation text.

## Data we do not collect

The app does not include advertising, does not require an account, and does not send analytics or document content to us.

## Permissions

- **Camera** — used only for document scanning when you start a scan.
- **Storage / media access** — used only to read files you pick and save outputs you create.
